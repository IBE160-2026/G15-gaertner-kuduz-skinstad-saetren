# README: zsh-kommandoer for passord og nøkkel

## 2026-11-26 kl. 16:00 — Ragnhild

### Oppgave
Rette README etter funnet fra den manuelle testen av story 5.9 på macOS: `IFS= read -rsp 'Ledetekst: ' VAR` feiler i zsh (`read: -p: no coprocess`), som er standard på macOS.

### Plan
- Bytte de to `read -rsp`-linjene (passord i steg 2 og nøkkel i live-avsnittet) med en variant som virker i både bash og zsh.
- Rette innledningen, som sa at bash-kommandoene gjaldt macOS.
- Rett på `main`, valgt av Ragnhild, fordi rettelsen ikke hører til story 5.9.

### Resultat
- README: ledeteksten skrives med `printf`, og `read` bruker bare `-r` og `-s`. Etikettene heter «bash og zsh». Commit `cc84eb4` på `main`, ikke pushet.
- Kontroll: begge linjene er kjørt ordrett fra README i bash og zsh med inndata fra rør. Mellomrom først og sist i passordet ble beholdt, og nøkkelen fikk riktig lengde. Skjult inntasting er ikke prøvd i en interaktiv terminal.
- Historiske omtaler av `read -rsp` i `docs/beslutninger/avklaringspunkter.md` og `docs/ki-logg/2026-11-06-innlogging.md` er ikke endret.

### Åpne punkter
- Prøv de nye linjene interaktivt i Git Bash på Windows og i zsh på macOS (at inntastingen ikke vises).
